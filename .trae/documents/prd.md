## 1. 产品概述

中国地质大学（北京）博达校区羽毛球场地预约助手，为校内师生提供便捷的场地查询、预约和自动抢场功能。
- 解决手动在微信中预约场地的不便，提供独立的桌面端预约界面
- 支持查询空位、费用展示、在线预约以及定时自动抢场

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 校内师生 | 微信授权登录（Token认证） | 查询场地、预约场地、自动抢场 |

### 2.2 功能模块
1. **登录页**: Token 输入/微信扫码登录，获取身份凭证
2. **场地查询页**: 日期选择、场地空位展示、费用展示、预约操作
3. **自动抢场页**: 定时任务配置、抢场状态监控、日志查看

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录页 | Token 输入 | 用户粘贴从微信获取的 Token，验证身份 |
| 场地查询页 | 日期选择 | 当日/明天/后天/大后天快速切换，更多日期日历选择 |
| 场地查询页 | 场地空位表格 | 10个场地的时段空位矩阵，颜色区分可约/已约/不可约 |
| 场地查询页 | 费用展示 | 每个时段的费用（白天10元/小时，晚上40元/小时） |
| 场地查询页 | 预约操作 | 选择场地+时段，提交预约，5分钟内完成支付 |
| 场地查询页 | 黑名单检查 | 预约前自动检查是否在黑名单中 |
| 自动抢场页 | 抢场配置 | 设置目标日期、场地、时段，7:30自动执行 |
| 自动抢场页 | 状态监控 | 实时显示抢场任务状态、执行日志 |
| 自动抢场页 | 倒计时 | 距离下次抢场的时间倒计时 |

## 3. 核心流程

用户登录 → 选择日期 → 查看场地空位 → 选择场地和时段 → 检查黑名单 → 提交预约 → 获取价格 → 完成支付

自动抢场流程：配置抢场任务 → 系统倒计时等待 → 7:30自动执行 → 查询空位 → 提交预约 → 通知结果

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深绿色(#0D7C3E) + 白色，呼应羽毛球场地的绿色地胶
- 辅助色：暖橙色(#FF6B35)用于强调和可操作状态
- 按钮风格：圆角8px，微阴影，hover时加深
- 字体：Noto Sans SC，标题18px加粗，正文14px常规
- 布局风格：顶部导航 + 卡片式内容区，左侧日期选择 + 右侧场地矩阵
- 图标风格：线性图标，2px描边

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 登录页 | Token输入 | 居中卡片，输入框+登录按钮，绿色渐变背景 |
| 场地查询页 | 日期选择 | 顶部横向日期标签栏，选中态绿色填充 |
| 场地查询页 | 空位矩阵 | 网格表格，行=时段，列=场地，绿色=可约，灰色=已约，红色=不可约 |
| 场地查询页 | 费用标签 | 每个格子右上角小字显示价格 |
| 自动抢场页 | 任务配置 | 表单卡片，下拉选择场地+时段，开关启用 |
| 自动抢场页 | 状态面板 | 大字倒计时，执行日志滚动列表 |

### 4.3 响应式
- 桌面优先设计，最小宽度1024px
- 移动端自适应：场地矩阵横向滚动
- 触摸优化：按钮最小44px点击区域
