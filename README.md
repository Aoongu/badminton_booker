# 🏸 CUGB 羽毛球抢场神器

中国地质大学（北京）羽毛球场地预约工具，基于 Cloudflare Worker 实现。

## ✨ 功能特性

### 核心功能
- 🔐 **微信登录** - 支持openid自动登录，无需手动输入Token
- 🔄 **自动重登** - Token失效时自动使用openid重新登录
- 👤 **用户名显示** - 登录后显示用户名，方便确认身份
- ⏰ **浮空倒计时** - 可拖动半透明浮窗，实时显示预约开放倒计时
- 🎯 **定时抢场** - 到点自动并发抢场，支持提前触发补偿延迟
- 🔍 **查询空位** - 一键查询可用场地，已满场次也可选中抢场
- 💰 **价格显示** - 已约场次显示价格信息
- 🚪 **退出登录** - 登录后可随时退出，切换账号

### 技术特性
- 🚀 Cloudflare Worker 边缘计算，全球加速
- 🔒 AES-128-CBC 加密通信
- 📱 响应式设计，支持手机/平板/电脑
- 💾 本地存储Token/OpenID，刷新不丢失
- ⚡ requestAnimationFrame 精确定时，200ms轮询 + 亚50ms触发

## 📦 部署方式

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. 进入 **Workers & Pages** → **Create Worker**
3. 点击 **Edit Code**
4. 将 `worker_v20.js` 内容全部复制粘贴
5. 点击 **Save and Deploy**
6. 访问分配的 `*.workers.dev` 域名即可使用

## 🔧 使用说明

### 使用流程

1. openid登录 → 选日期 → 点「查询空位」
2. 点选格子 → 启动定时 → 自动抢场
3. 收到成功提示后去订单界面支付

### 获取 openid（推荐）

1. 在微信小程序中打开羽毛球预约页面
2. 使用抓包工具（如 Charles）捕获请求
3. 找到 `wxLogin` 请求，解密 `item` 字段获取 openid
4. 粘贴到输入框，点击"微信登录"

### 或直接输入 Token

1. 从抓包请求中获取 `token` 字段
2. 粘贴到"身份令牌"输入框

## 🔐 关于 openid 和 Token

| 项目 | openid | Token |
|------|--------|-------|
| 获取方式 | 抓包解密wxLogin请求 | 抓包获取请求头 |
| 用途 | 换取Token | 调用API |
| 推荐度 | ⭐⭐⭐ 推荐 | ⭐ 备用 |

## ⚠️ 注意事项

1. **预约限制**: 只能预约三天内（今天/明天/后天）的场次
2. **开放时间**: 每天 07:30 开放预约
3. **网络延迟**: 可设置提前触发时间补偿延迟（默认200ms）
4. **定时精度**: 距目标2秒内自动切换高精度模式
