# 🏸 CUGB 羽毛球抢场神器

中国地质大学（北京）羽毛球场地预约工具，基于 Cloudflare Worker 实现。

## ✨ 功能特性

### 核心功能
- 🔐 **微信登录** - 支持openid自动登录，无需手动输入Token
- 🔄 **自动重登** - Token失效时自动使用openid重新登录
- 👤 **用户名显示** - 登录后显示用户名，方便确认身份
- ⏰ **倒计时** - 实时显示预约开放倒计时
- 💰 **价格显示** - 已约场次显示价格信息

### 技术特性
- 🚀 Cloudflare Worker 边缘计算，全球加速
- 🔒 AES-128-CBC 加密通信
- 📱 响应式设计，支持手机/平板/电脑
- 💾 本地存储Token/OpenID，刷新不丢失

## 📦 部署方式

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. 进入 **Workers & Pages** → **Create Worker**
3. 点击 **Edit Code**
4. 将 `worker_v18.js` 内容全部复制粘贴
5. 点击 **Save and Deploy**
6. 访问分配的 `*.workers.dev` 域名即可使用

## 🔧 使用说明

### 首次使用

1. **获取 openid**（推荐）
   - 在微信小程序中打开羽毛球预约页面
   - 使用抓包工具（如 Charles）捕获请求
   - 找到 `wxLogin` 请求，解密 `item` 字段获取 openid
   - 粘贴到输入框，点击"微信登录"

2. **或直接输入 Token**
   - 从抓包请求中获取 `token` 字段
   - 粘贴到"身份令牌"输入框

### 预约流程

1. 选择预约日期（今天/明天/后天）
2. 设置开放时间（默认 07:30）
3. 点击场次格子选择要预约的场地
4. 等待倒计时结束，自动发起预约请求
5. 查看预约结果（成功/失败）

| 推荐度 | ⭐⭐⭐ 推荐 | ⭐ 备用 |

## ⚠️ 注意事项

1. **预约限制**: 只能预约三天内（今天/明天/后天）的场次
2. **开放时间**: 每天 07:30 开放预约
3. **网络延迟**: 可设置提前触发时间补偿延迟（默认200ms）
